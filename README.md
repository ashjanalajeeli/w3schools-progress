# W3Schools Progress

لوحة تعليمية عربية مدمجة بأسلوب الملف الشخصي، تعرض إنجازات التعلّم ومهارات المسارات عبر مخطط أعمدة ومخطط دائري، من دون جدول دروس منفصل.

## البيانات

عدّلي `progress.json` لتغيير عدد الدروس المنجزة لكل مسار. المخططات والملخصات تُبنى من هذه البيانات عند فتح الصفحة.

## التشغيل محليًا

لأن الصفحة تقرأ ملف JSON عبر `fetch`، شغّلي خادمًا محليًا من مجلد المشروع، مثلًا:

```bash
python3 -m http.server 8000
```

ثم افتحي `http://localhost:8000`.
